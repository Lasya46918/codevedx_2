# Project 2 — Student Performance Prediction System

## Objective
Estimate final marks from attendance, previous marks and daily study hours.

## Features
- CSV dataset and record viewing/addition.
- Random Forest regression.
- Train/test split, MAE and R² evaluation.
- Actual-vs-predicted chart and feature-importance chart.
- Prediction for a new student.

## Run
```bash
pip install -r ../requirements.txt
python main.py
```
Select **Train model** before predicting. The included small dataset is synthetic/demo data; use an appropriate approved dataset for meaningful evaluation. This tool should support, not determine, academic decisions.
